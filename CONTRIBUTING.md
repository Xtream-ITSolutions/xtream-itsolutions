# Mitwirken

Vielen Dank für dein Interesse an Xtream-ITSolutions.

## Vor einer Änderung

Bei größeren Änderungen oder neuen Funktionen bitte zunächst ein Issue eröffnen oder Kontakt aufnehmen. So können Ziel, Umfang und technische Richtung vorab abgestimmt werden.

## Pull Requests

Pull Requests sollten:

- eine klar abgegrenzte Änderung enthalten,
- eine verständliche Beschreibung und Testhinweise mitbringen,
- keine Zugangsdaten, Tokens oder personenbezogenen Daten enthalten,
- bestehende Konventionen und Dokumentation berücksichtigen.

Bitte beschreibe im Pull Request kurz, **was** geändert wurde, **warum** die Änderung nötig ist und **wie** sie geprüft wurde.

## Fehler und Sicherheitsprobleme

Für normale Fehler kannst du ein Issue eröffnen. Sicherheitslücken bitte vertraulich gemäß [SECURITY.md](SECURITY.md) melden.
